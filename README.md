# VFX Studio Texture Library

A texture library for Roblox developers.

## Licensing Instructions

You must submit a signed agreement before using this library in your Roblox project.

1. Read [LICENSE.md](./LICENSE.md).
2. Download [VFX_Studio_License_Agreement.pdf](./VFX_Studio_License_Agreement.pdf).
3. Fill out your details in Section 1 (Roblox ID, Discord ID, Place/Plugin ID) and sign Section 10.
4. Send the completed PDF via Discord DM to `limited_qj` (Discord ID: `884419050711699456`).
5. Once you receive the signed copy back, your license is active.

## Main Rules

- Each game, place, or plugin requires its own separate license.
- You cannot edit, recolor, or modify the texture assets.
- You cannot sell or share the raw asset files.
